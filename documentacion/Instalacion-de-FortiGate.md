# 🛡️ Instalación de FortiGate

En esta etapa se realizará la instalación de **FortiGate VM** sobre **VMware Workstation**, que posteriormente funcionará como firewall principal y gateway de la infraestructura del laboratorio **SOC-Lab**.

---

## 📋 Requisitos de la Máquina Virtual

| Parámetro | Configuración |
|------------|---------------|
| Plataforma | VMware Workstation |
| Producto | FortiGate VM |
| Formato | OVF |
| CPU | 2 vCPU |
| Memoria RAM | 2 GB |
| Red WAN | VMnet8 (NAT) |
| Red LAN | VMnet2 (Host-Only) |

---

## ⚙️ Procedimiento de Instalación

La instalación se realizará mediante la importación de la imagen **OVF de FortiGate** en VMware Workstation. Posteriormente, se verificará la configuración del hardware virtual y de los adaptadores de red antes de iniciar el firewall.
